# RAG 训练营参考资料

本目录保存项目所有者获授权使用和公开再分发的 RAG 学习资料，用于 TraceDesk 后续的方案复核、模块对照和面试准备。它是参考资料归档，不属于 TraceDesk 的运行时代码、依赖或正式验收证据。

为避免泄露凭据、重复提交可恢复内容以及无谓增大仓库，本目录不跟踪：

- `.env` 等本地环境配置和嵌套仓库的 `.git` 元数据；
- `node_modules`、虚拟环境、Python 字节码和各类工具缓存；
- 构建产物、Notebook checkpoint、数据库/向量库运行卷；
- ONNX、词典索引和其他可重新获取或生成的大型模型资源。

示例环境文件、依赖清单、源码、Notebook、讲义、配图和授权样例文档仍保留，便于理解原始课程结构。使用其中代码或方案时，应重新验证依赖版本、安全边界和与 TraceDesk 当前架构的兼容性，不能把课程示例本身视为 TraceDesk 已完成的实现或验收证据。
