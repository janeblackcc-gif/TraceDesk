# 生成证据约束迁移样例

8 个 AI 合成的受控样例，4 个可答、4 个缺证据；由另一代理拟定，主代理在运行前修正题目与必要事实的对应关系。原文、问题和判分规则在首次调用生成模型前按 SHA256 冻结。没有真实用户参与，也不是独立人工评估。

直接向同一生成器提供固定证据，不运行检索。只把 question 和 evidence 发给模型，kind、mandatory_facts、refusal_reason 不进入请求。每题只运行一次，不根据结果修改题目、标准或生成流程。

正例同时要求结论正确、mandatory_facts 全部覆盖、每条结论得到自己的引文支持。允许语义等价表述。负例要求 abstain=true 且 claims=[]；混合可答和不可答子问题遵循当前全问拒答协议。通过 source_id 与逐字引用检查不代表语义通过，结果需单独代理复核。

拒答材料大多明确指出所问事实位于其他资料，因此这是一组偏清晰的边界样例，不能替代自然文档中的隐含缺失、长上下文或对抗测试。
