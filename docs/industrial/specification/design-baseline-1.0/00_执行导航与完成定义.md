## 2. 三个高价值待确认问题

不等待答案也可以按默认方案开工，但答案会显著改变范围：

1. **首批部署边界？** 默认：同一实验室/小研发团队内部，5–20 个注册成员，单组织，非公网匿名服务。若要互联网/跨组织开放，认证、TLS、滥用防护、合规与容量门槛前移。
2. **首批规模和预算？** 默认：≤20 用户、≤5 并发查询、≤50,000 活跃 chunk、原文件≤20 GB；一台 Linux 主机运行应用/数据库，Ollama 可同机或独立 GPU 主机。若≥200,000 chunk、≥20 并发或要求 HA，需重新容量设计。
3. **资料能否离开受控环境、是否已有组织 IdP？** 默认：资料不发送云模型；使用本地 Ollama；首版本地账号+服务端会话。若已有 OIDC/SSO，应在真实试用前接入；若允许云模型，只能作为显式 provider 并独立评测，不能静默回退。

## 3. 默认方案

- 单组织内部部署；知识库有成员 ACL。
- 角色：系统管理员、工作区管理员、知识库编辑者、知识库查看者。
- MD/TXT/文本 PDF 为默认格式；OCR 架构预留但不默认启用。
- 保留原文件、解析产物、chunk、索引代次；重解析/重建不依赖用户重新上传。
- Linux 为建议生产环境；Windows 11 + RTX 4060 Ti 8GB 保留为开发/模型验证环境。
- PostgreSQL 18 + pgvector；后台任务也用 PostgreSQL 租约队列，不引入 Redis/Celery。
- FastAPI 与当前前端保留，演进为模块化单体 + 独立 worker；不以微服务/Kubernetes证明工业化。
- 当前 4B 本地模型只是起点；是否升级由质量消融决定。
- 真实用户、真实数据授权、人工评审是试点门禁，不能用编造材料替代。

## 5. 五种完成状态

- **设计通过**：文档内部一致，关键决策有默认值，任务可追踪。
- **编码完成**：代码合并且任务自身测试通过。
- **工程验收通过**：全新环境、迁移、权限、并发、任务恢复、备份恢复、升级回滚、安全与容量门禁通过。
- **质量达标**：冻结 holdout 的正确性、完整性、证据支持、拒答达到批准阈值；不挑成功重跑。
- **真实试用通过**：真实授权资料和真实用户在约定周期证明可持续使用。打包成功、CI 绿灯或演示流畅都不能替代。

## 6. 未决事项分类

### 阻塞架构选择
- 是否跨组织/公网：默认单组织内部；最迟 M1 结束前确认。
- 是否显著超过 50k chunk / 5 并发：默认不超过；最迟 M4 前确认。
- 是否必须组织 OIDC：默认本地账号；最迟 M2 开工前确认。

### 阻塞对外部署/真实试用
- 真实用户、真实资料授权、数据保留要求：M6 数据集冻结前必须有。
- 云模型/本地模型边界：M6 模型比较前必须有。
- 目标硬件、并发与延迟预算：M8 容量测试前冻结。

### 编码时可确认
- UI 文案、分页默认 50、日志保留 30/90 天、解析临时目录配额等：按本文默认值实现，再由测试校准。

## 7. 工业化完成条件

1. `PC-*` 需求全部映射到 `T-*` 开发任务与 `FA-*` 验收。
2. 数据迁移有 dry-run、校验、备份、重复执行、失败恢复证据。
3. 替换/删除/模型变化时旧任务不能写回；旧 doc/chunk ID 有兼容解释。
4. 权限覆盖检索、来源、trace、导出、任务结果、评测。
5. 解析超时能终止子进程并回收临时资源。
6. 备份恢复后原文件、权限、活动索引、关键查询一致。
7. 混合负载达到冻结 SLO，错误和排队有界。
8. 冻结 holdout 达到质量门槛；开发题不冒充独立测试。
9. 至少一次真实小范围持续试用完成并保留失败。
10. `09_设计审查与未决事项.md` 的阻断项关闭或由负责人书面接受风险。
