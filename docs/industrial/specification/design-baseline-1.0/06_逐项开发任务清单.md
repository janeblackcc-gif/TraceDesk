# TraceDesk 逐项开发任务清单

> 估时均为**规划估计，不是承诺**。`拟新增` 表示当前源码不存在。所有任务的证据统一写入 `artifacts/<milestone>/<task-id>/`（拟新增），CI/验收不得只看终端截图。

## 执行规则

- 必须串行：数据 schema → 迁移 → ACL → job 基础 → revision/解析 → 索引代次 → v1 API → 运维/容量。
- 可并行：M6 真实数据准备可在 M2–M5 工程期间进行；监控基础可与 M5 并行。
- 每个任务 PR 只做一个主要架构/算法变量；基础依赖升级单独 PR。
- 任何任务失败先保留日志和失败 fixture；禁止删测试、放宽 gold 或把异常吞掉。
