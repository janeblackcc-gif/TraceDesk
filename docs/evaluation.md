# 评测与已知限制

## 题集

当前公开题集包含Atlas虚构技术文档回归、[tracedesk_ops开发集](../datasets/tracedesk_ops/README.md)，以及运行前冻结的[FastAPI外部文档挑战集](../datasets/fastapi_zh_challenge_v1/README.md)。tracedesk_ops为3份依据v0.1时期真实代码与本机配置整理的短文档，共17个分块，12道AI拟定问题，其中10道可答、2道不可答。

新增挑战使用六篇官方资料、133个分块、24题，三种方法共72条全部完成。三种方法Hit@4均为18/18，但严格通过均为13/24；已发现无依据补答、拒答状态不一致及引用语义不匹配。结果与修复优先级见[外部评测报告](external-evaluation.md)，不能用下文较简单开发集上的成绩替代外部表现。

tracedesk_ops是冻结的历史资料快照。0.2版本已增加.env读取；OPS04仍按旧资料评分，用于比较引用协议，不作为当前部署说明。当前使用方式见[部署文档](deployment.md)。这些题不是独立测试集或真实用户问题，语料较小且措辞接近原文。

## 引用协议对照

2026-09-08在同一Windows电脑、Ollama 0.33.3、同一模型digest、资料和已建立索引上，分别运行旧版自由抄写引用与新版来源编号选择协议。每轮每种方法先预热一次，再按题号轮换BM25、dense、hybrid，正式采样均为12题乘3种方法，各36次。

嵌入为qwen3-embedding:0.6b-q8_0，生成为qwen3.5:4b-q4_K_M；上下文8192，最大输出768 tokens，temperature=0，seed=42，think=false。检索实现与阈值保持一致；生成提示、结构化输出协议和原文呈现方式随引用方案一起变化。

| 方法 | Hit@4 旧/新 | 可答题有效模型回答 旧/新 | 无答案正确拒答 旧/新 | 引用降级 旧/新 | 总耗时P50 ms 旧/新 |
|---|---:|---:|---:|---:|---:|
| BM25 | 10/10 → 10/10 | 9/10 → 10/10 | 2/2 → 2/2 | 1 → 0 | 2838.93 → 1601.42 |
| dense | 10/10 → 10/10 | 9/10 → 10/10 | 2/2 → 2/2 | 1 → 0 | 4172.07 → 3046.72 |
| hybrid | 10/10 → 10/10 | 9/10 → 10/10 | 2/2 → 2/2 | 1 → 0 | 4096.55 → 3048.82 |

两轮的Recall@5和MRR@5均为1.0，本题集没有显示混合检索的质量优势。耗时为小样本单轮观察，不能解释为稳定性能保证；生成内容长度也发生了变化，不能把全部耗时差异归因于引用字段缩短。

旧版OPS04把原文中的空格删除，严格引用校验因此触发降级。新版模型只选择给定的source_id，由后端恢复原文；该题三种方法均恢复有效回答。最终逐字校验继续执行。

## 语义复核

Codex逐题对照问题、参考答案、最终结论及原文引用，复核了每轮36条结果；这不是独立人工标注。旧版每种方法核心通过11/12，新版为12/12，包括2次正确拒答。核心通过要求正文回答核心问题且所有结论有引用依据，降级不计有效模型回答。

采用更严格的参考答案全文覆盖口径时，旧版均为7/12；新版BM25为11/12，dense与hybrid为10/12。新版OPS05仍未在正文补充文件必须非空；dense/hybrid的OPS02未明确写出PowerShell 7。部分回答展开过多，格式题中也有重复结论。

这些是开发集上的代理复核结果，不能对外宣称真实用户准确率100%。来源编号选择也不能证明每条结论在语义上受到支持，测试中专门保留了这一边界。

公开记录位于[旧版结果](../eval/baselines/ops_v1/summary.json)与[新版结果](../eval/baselines/ops_v2/summary.json)。对应目录保留逐题响应、生成请求和回复、模型与代码哈希、语义标注。导出省略本机绝对路径、运行数据库、query向量及模型仓库的机器元数据。

## 复跑

先按[题集说明](../datasets/tracedesk_ops/README.md)导入冻结资料并建立索引，再从项目根目录执行：

```powershell
./.venv/Scripts/python.exe scripts/run_baseline.py --dataset datasets/tracedesk_ops
```

默认读取项目配置中的数据库与Ollama地址。脚本只读复制所选资料和向量到新评测库，复用Service.ask执行问答。结果写入evidence/baselines的新目录，已有目录不会覆盖；原始结果保留在本机。

默认预算900秒，在请求之间检查，单次模型请求超时120秒。退出码0为执行完成，2为逐题错误，1为整轮错误，130为用户中断。执行完成不等于答案全部正确。

Hit@4统计前4个上下文片段是否命中标注相关块；Recall@5统计相关块召回比例；MRR@5统计首个相关块的倒数排名。gold_coverage_at_4检查多条必要原文的覆盖。拒答、误拒答、引用失败降级和耗时单独记录，语义正确性另行复核。

Windows 11 / Python 3.13.14下，本机开发环境与从候选ZIP解压的新目录、新虚拟环境均通过89项测试；新环境依赖检查、启动诊断和两个本地模型就绪检查通过。测试中仍有一条Starlette依赖对AnyIO旧别名的弃用警告。

新版已通过真实HTTP与Microsoft Edge无头浏览器验收，完整流程用时22.222秒，退出码0。流程覆盖空库、演示版本端口、精确引用高亮、上传、真实向量索引、模型回答与拒答、同名替换、重建索引、删除与旧来源失效。备份间隔由7小时改为13小时后，模型回答新值；无联系电话资料时拒答。桌面1440×1000与移动390×844视口无横向溢出，未记录到JavaScript或网络错误。
