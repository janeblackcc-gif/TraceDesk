# 证据规划与拒答修复回归

2026-09-08 完成一轮生成流程修复。FastAPI 冻结题集上的严格通过由三种方法各 13/24，变为 BM25 21/24、dense 18/24、hybrid 22/24；18 条无答案请求全部正确拒答。原运维集核心回答保持正确，但参考答案全文覆盖下降。本轮属于开发回归，不能解释为独立测试准确率，也不足以证明语义问题已经解决。RC1 发布标签和安装包保持原样，改动进入 main 的未发布部分。

## 改动与原因

RC1 允许模型先写结论再选择来源。真实片段中的构建进度 100% 被写成镜像 100 MB，仍可通过来源编号与逐字引用校验。该校验能够确认引用真实存在，不能判断数字的单位、对象或命题是否受到支持。

先对 12 个固定开发样本测试额外的草稿审核调用：它拦住部分误答，却仍放过单 worker 最多处理一个请求及重启方面的矛盾。该方案未进入应用。随后改为一次调用内逐项查找问题所需事实，再写结论；12 个诊断样本的全部 6 个负例拒答，但部分正例仍漏细节，因此在正式回归前补充子问题覆盖要求。

当前 [providers.py](../app/providers.py) 输出逐项的 required_fact、source_ids、evidence_finding、supported、answer。后端严格校验类型和字段关系，任一必要事实缺失就统一返回 abstain=true 与空 claims。缺失事实可以附上已查阅但不足的有效片段编号，不能带出生成答案。全部事实齐备时，继续由后端从本轮编号构造原文引用。

未知来源编号触发可见的原文摘录降级；非正常完成、截断、无效 JSON 或不一致结构作为执行错误返回。响应、trace 和 Markdown 导出保留生成策略、逐项证据判断、缺失事实和耗时。这些都是模型判断，不是独立事实核验。当前采用整问拒答，混合可答和不可答子问题不会输出部分答案。

模型、检索、切块和阈值沿用 RC1：Ollama 0.33.3、qwen3-embedding:0.6b-q8_0、qwen3.5:4b-q4_K_M，温度 0、seed 42、上下文 8192、thinking 关闭。每次仍只有一个生成请求；输出预算由 768 增为 1536，以容纳结构化证据判断。

严格通过要求可答题正文正确、必要事实完整、每项结论由自己的引用支持，并实际返回模型回答；负例要求 no_evidence 且 claims 为空。由主代理与两个只读代理逐项复核，边界表达另行交叉校准。允许语义等价；引用中出现但正文未表达的事实不算正文完整。单轮、小样本、输出长度变化使计时不能作为稳定性能保证。

最终 72 条于 14:11:52 至 14:18:47 UTC 完成，约 415 秒，退出码 0，无执行错误和引用降级。原始结果 SHA256 为 e29acdd48cd918ee8701facb530871a3d30f2fb65c5dfad65a542f65f6c2261a。公开 [请求和响应](../eval/baselines/fastapi_evidence_first/results.jsonl)、[语义复核](../eval/baselines/fastapi_evidence_first/semantic_review.json)、[汇总](../eval/baselines/fastapi_evidence_first/semantic_summary.json)和[哈希清单](../eval/baselines/fastapi_evidence_first/SHA256SUMS)可核查。

首轮开发回归另外保留 72 条原始记录，其中 FA02/bm25 因 supported=false 却附有有效片段编号而触发结构错误。修正解析规则后完整重跑，72 对模型请求和原始输出均逐字相同，71 条成功结果的正文及引用也相同；唯一行为变化是该请求正常拒答。未挑选单题重跑结果拼成最终批次。最终运行的顶层说明已从数据集首次运行说明更正为开发回归，修改前后哈希在本机 metadata_annotation.json 中保留；冻结题目和原始问答字节未变。

仍有以下失败：

- FA02/bm25 和 FA07/dense 在全语料中可答，但当前前4块缺少部分必要事实，整体拒答。按题集可答性计误拒答，不能解释为所有必要证据均在场时的无故拒答。
- FA05 仍会用 FAQ 问题标题推断 shell 导致约 10 秒停机，或 exec 可避免耗时过长；现有引文没有提供完整因果依据。
- FA06、FA14 等仍可能选择正确知识块中的错误原文段，导致自己的引用没有覆盖全部结论。
- FA03/dense 遗漏重复工作并把可能发生冲突写成会发生冲突；FA15 部分方法遗漏 worker 对复制或重启的作用程度。
