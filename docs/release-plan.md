# 首个开源版本验收清单

前五节已勾选项目对应RC1首发验收，末节记录RC2。RC2已完成179项测试与38项真实浏览器功能检查并公开发布，见[安装验收](assets/rc2-browser-acceptance/README.md)及[当前质量边界](rc2-evaluation.md)。

目标是可由他人部署的本地单人技术文档问答工具。正式版本需要完成安装、资料管理、真实模型问答、引用核验与评测的完整流程。当前发布范围采用本机回环地址，公网演示另行设计访问与资源控制。
