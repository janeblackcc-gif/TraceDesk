# 首个开源版本验收清单

目标是可由他人部署的本地单人技术文档问答工具。正式版本需要完成安装、资料管理、真实模型问答、引用核验与评测的完整流程。当前发布范围采用本机回环地址，公网演示另行设计访问与资源控制。

## 仓库与配置

- [x] 初始化 Git 仓库，保留原始实验与交付材料。
- [x] 为私有配置、数据库、模型、日志与历史咨询材料设置忽略规则。
- [x] 核对实际发布文件，确保测试和示例依赖均在仓库内。
- [x] 统一配置优先级，去除启动脚本对开发机绝对路径的默认依赖。
- [x] 提供无需启动网页的配置与模型诊断命令。
- [x] 添加自动化测试工作流并记录本机验证范围。

## 核心流程

- [x] 本机真实嵌入与生成模型接入，模型 digest 与索引绑定。
- [x] 文档导入、版本隔离、替换及删除的基础测试。
- [x] BM25、向量与混合检索的首版批量基线。
- [x] 修复模型改写引用空格引发的降级，验证错误编号与非原文引用被拒绝；结论语义仍需复核。
- [x] 验证启动、导入、索引、问答、引用定位、更新和删除的完整使用流程。
- [x] 验证空知识库、无答案、错误配置和端口占用；模型不可用分支由模拟连接失败测试覆盖。
