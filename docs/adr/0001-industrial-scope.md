# ADR-0001：单组织内部部署与模块化单体

状态：采用文档默认值；用户可在相关里程碑前修订。
关联：T-002；PC-01 至 PC-20。

保留 FastAPI、现有前端和本地 Ollama，面向 5–20 名成员、5 并发查询、
50,000 活跃 chunk、20 GB 原文件。Linux/Compose 是目标运行环境，Windows 是开发验证环境。
Web 与独立 worker 共用领域服务。首批不引入跨组织 SaaS、云模型回退或 Kubernetes。
本轮迁移期间 RC2 本机运行路径保留，团队入口完成认证和迁移前不得接管真实资料。

工业化完成需要 M0–M9 门禁。真实资料授权、正式质量阈值、目标资源和真实试用
不能由测试 fixture 或编码代理代签。范围改变时新增 superseding ADR。
