# Atlas 新人入门 · v2
本页属于原创虚构演示项目 Atlas。配置仅用于演示，不代表 TraceDesk 的运行要求。

## Python 运行环境
Atlas v2 要求 Python 3.11，先创建独立虚拟环境，再安装锁定依赖。不要复用另一个版本的虚拟环境。

## 本地启动顺序
启动顺序为：复制 .env.example 为 .env，执行 python -m atlas.migrate，然后执行 python -m atlas.server。
服务默认监听 127.0.0.1:8088，仅允许本机访问。

## 健康检查
健康检查路径为 /ready；响应包含 status=ready 和 schema_version=2。
检查失败时先确认迁移命令完成，再检查端口是否被占用。

## 项目权限申请
新人向项目维护人申请 reader 权限，完成演示数据练习后才能申请 editor 权限。申请记录保存在团队工单，不通过聊天口头授权。

## 代码提交规范
提交说明采用 type: summary 格式。修复问题使用 fix，新增功能使用 feat。合并前必须通过单元测试和格式检查。

## 首次排查材料
提交故障工单时附带版本号、错误码、脱敏日志和复现步骤。禁止在工单中粘贴访问令牌或真实用户信息。
